# Squadriglia Pulcino Pio · 5ATA

Questo è il sito della squadriglia: **https://www.5ata-pulcinopio.ata-lucarelli.it**

## Come si modifica

1. Aprite questo repository su github.com e premete il tasto **`.`** (punto) sulla tastiera:
   si apre un editor nel browser.
2. Modificate i file:
   - `index.html` per i testi (chi siamo, squadra, progetti, diario);
   - `style.css` per i colori, che sono in cima al file;
   - la cartella `img/` per le immagini, che si caricano trascinandole nell'editor.
3. A sinistra, nell'icona **Source Control**, scrivete cosa avete cambiato (per esempio
   "aggiunto diario 16 ottobre") e premete **Commit & Push**.
4. Dopo circa un minuto il sito è aggiornato.

## Regole

- **Non cancellate né modificate il file `CNAME`**: è quello che collega il sito al suo indirizzo.
- Niente cognomi completi, numeri di telefono, indirizzi email o foto di persone senza permesso.
- Le immagini vanno in `img/` e si richiamano così: `<img src="img/nome-foto.jpg" alt="descrizione">`.
